## Deliverables
1. `instruction.rs`: `#[derive(Copy)] struct Instruction(u32)`; accessors/builders for every format in the active version (`iABC`, `ivABC` [5.5], `iABx`, `iAsBx`, `iAx`, `isJ`), `opcode()` returning `Option<OpCode>` (**total on any 7-bit value**; never UB/panic on bad input), `MAXARG_*` consts, signed-arg helpers. 2. `rn-compiler/src/undump.rs` + `dump.rs`: `undump<H: CompilerHost>(host, bytes, chunk_name) -> Result<ProtoData<H::Str>, CompileError>` and `dump(&ProtoData<S>, host, strip) -> Vec<u8>`. Header checks and every error message identical to `lundump.c` (e.g. `truncated chunk`, `bad binary format (...)`, `version mismatch`, `format mismatch`). Must be **robust**: arbitrary/truncated bytes never panic or loop; counts validated before allocating (no huge `Vec::with_capacity` from untrusted sizes).
   Wire `load()` in `lib.rs`: text starting with ESC (0x1b, `LUA_SIGNATURE[0]`) → undump if `mode.binary` else the reference "attempt to load a binary chunk (mode is 't')" error; text → (lexer/parser later; for now return `"not implemented"`).
3. `lexer.rs`: faithful port of `llex.c` (tokens incl. 5.5 additions: check the vendored `llex.h`/`llex.c` — reserved words list differs; decimal/hex ints & floats, hex floats, long brackets/comments, all escapes `\z \x \u{...} \ddd \a...`, line counting with `\r\n` normalization, shebang line skip is done by `luaL_loadfilex` not the lexer, `lookahead`). Lexical error messages must be byte-identical (`chunk:LINE: msg near 'tok'`, chunk name shortening per `luaO_chunkid` — implement `chunkid` here as `pub fn chunk_id(source:&[u8]) -> Vec<u8>` using `LUA_IDSIZE = 60`). Numerals: call `rn_core::number::str2num` (**Builder B is implementing it; currently a stub returning None**). Until it lands, test numerals with a local `#[cfg(test)]` stand-in and leave a `TODO(B1)` note; do not reimplement it in the crate.
   Public API shape is yours but must be reusable by the A2 parser (`LexState` with `next_token()`, `lookahead()`, `token`, `line_number`, error raising returning `CompileError`).
