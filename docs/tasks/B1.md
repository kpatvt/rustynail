## Goal
Value representation, number semantics/formatting, the fallible allocator layer, strings with interning, and a minimal `Heap` that implements `CompilerHost`. No tables/GC collection/VM yet (tasks B2+).

## Upstream references (read before writing)
`lobject.h/.c` (TValue, variant tags, `luaO_str2num`, `l_str2int`, `l_str2d`, `lua_strx2number`, `tostringbuff`/`lua_numbertocstring`, `luaO_utf8esc`, `luaO_chunkid` is Builder A's), `lvm.c`/`llimits.h` (integer division/modulo, shifts, float<->int conversions `luaV_flttointns`, `luaV_equalobj` number cases, `LTnum/LEnum` exact int/float comparison), `lmem.c/.h`, `lstring.c/.h` (`luaS_hash`, string table, short-string limit `LUAI_MAXSHORTLEN`=40, cache), `luaconf.h` (number formats).

## Deliverables (in this order)
1. `number.rs`: exact `str2num` (decimal & hex ints with wraparound for hex, decimal ints overflowing to float, hex floats with binary exponent, leading/trailing whitespace, `inf`/`nan` rejected, locale-independent '.'), `tostring` for numbers per version (**5.5: `%.15g`, fall back to `%.17g` if it doesn't round-trip, append `.0` if it looks like an int; 5.4: `%.14g`** — confirm in vendored `lobject.c`/`luaconf.h`), integer ops: `idiv`, `imod` (floor semantics, `LUA_MININTEGER // -1`), shifts (`luaV_shiftl` semantics for |n|≥64), float `fmod`/`pow` helpers, `float_to_int_exact`/floor/ceil modes, exact int<->float comparisons (no precision loss). Implement `%g` via Rust `format!("{:.*e}")` + manual formatting (or `libc::snprintf` where simplest) — whichever is verifiably identical to libc.
2. `alloc.rs`: `Allocator` trait with `lua_Alloc` semantics (`realloc(ptr, old, new)`, new==0 frees), a `SystemAllocator`, fallible `RawBuf<T>` (try-grow/shrink returning `Err(Status::ErrMem)`), memory-accounting counter (total bytes, for GC debt later). `unsafe` allowed here.
3. `value.rs`: 16-byte `#[repr(C)] Value { tag: u8, payload }` using the reference variant numbering (`LUA_VNIL`, `LUA_VEMPTY`, `LUA_VABSTKEY`, `LUA_VFALSE/VTRUE`, `LUA_VNUMINT/VNUMFLT`, `LUA_VSHRSTR/VLNGSTR`, …; copy from the vendored `lobject.h`), safe typed accessors, constructors, `type_of()`, truthiness, `raw_equal` for the non-object cases. `unsafe` confined here with `// SAFETY:`. Assert `size_of::<Value>() == 16` in a test.
4. `string.rs` + `heap.rs`: GC object header (`next`, `tt`, `marked`), `LuaString` (short interned ≤40 bytes; long strings with lazy hash; **must allow externally-owned buffers** for 5.5 `lua_pushexternalstring`), `luaS_hash` identical to reference with seed, string table with chained interning and resize, `Heap` owning the allocator + string table, and `impl CompilerHost for Heap` (`Str = StrRef` handle, `intern`, `bytes`). No collection yet: the Heap frees everything on `Drop`; keep the object list so B2's mark/sweep can plug in. `unsafe` confined to these two files + `gc/`.
