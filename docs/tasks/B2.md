## Deliverables
1. **`table.rs`** — faithful port of 5.5 `ltable.c`: array part (**5.5's array-part layout/sizing — read the vendored source; it differs from 5.4**) + node hash part with Brent's-variation chained scatter, `lastfree`, `rehash`/`computesizes`/`numusearray`/`numusehash`, `luaH_resize`, `luaH_getn` (border via binary search, "limit" hint semantics in 5.5), `luaH_next` (exact iteration order: array part then node order), `luaH_get/getint/getshortstr/getstr/get_generic`, `luaH_newkey` (float keys normalized to int when exactly integral; NaN / nil keys rejected via a returned `TableError::{NilIndex, NanIndex, Mem}` — the VM converts to Lua errors), `luaH_set`/`finishset`, `luaH_new`/`free`. Node layout compact (key tag+value tag packed like the reference where it helps; 24–32 bytes/node). Metamethod-absence `flags` byte (bits for `__index`, `__newindex`, `__gc`, `__mode`, `__len`, `__eq`, … exactly as `ltm.h`'s `maskflags`) + `invalidate_tm_cache` on any write to the table when it could be a metatable (as `invalidateTMcache`). Fast paths `#[inline]`; slow paths `#[cold]`. Table metatable pointer field present (type `*mut Table`/`Option<TableRef>`).
2. **`gc/` G1: stop-the-world, precise, non-moving mark & sweep** matching `lgc.c` object model: tri-colour bits + current/other white (so G2 incremental can follow), `GcHeader` shared by all object kinds, `Heap::collect()` taking a **root-marking callback** (`FnMut(&mut Marker)`) because `State` does not exist yet; `Marker::mark_value/mark_object`. Objects handled now: strings (short strings removed from the string table on free via `remove_short`), tables (array/hash traversal, metatable), plus a **`GcObject` kind enum/registry designed so closures/upvalues/protos/userdata/threads can be added by B3 without redesign** (dispatch on `tt`). Weak tables (`__mode` k/v/kv) and ephemerons with `clearbykeys/clearbyvalues`, `convergeephemerons` and the "resurrected object" cases from `lgc.c` — implement now, even if exercised only via tests that mark from a root callback. Finalizer (`__gc`) bookkeeping lists (`finobj`, `tobefnz`, `separatetobefnz`, `callallpendingfinalizers`) as data structures + the separation/resurrection logic, with the actual calling of finalizers left as a callback hook for B3. Write-barrier entry points (`barrier`, `barrier_back`) present and no-ops/trivially correct under stop-the-world (so call sites exist from day one). `GCdebt`/threshold accounting from `Mem::total` and `Heap::check_gc()` as the **safepoint** function (PLAN §4.6: collection only at explicit safepoints). Parameters via a `GcParams` struct (pause, stepmul, stepsize) with 5.5 semantics (read `lgc.h`/`lgc.c`).
3. **String cache / `luaS_new`** can be skipped; but fix B1's known gaps: make `intern_short` resurrect dead-but-unswept short strings (`isdead`/`changewhite` as in `internshrstr`), and extend `Heap::drop` to free all object kinds.
4. **Test GC stress hook:** env var `RUSTYNAIL_GC_STRESS=1` makes every `check_gc()` safepoint run a full collection (PLAN V8). Document in code.
