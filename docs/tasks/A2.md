## Goal
`rn_compiler::load()` compiles Lua 5.5 source text into `ProtoData` whose **bytecode listing is textually identical to `ref/55/build/luac -l -l`** for the whole corpus. This is the single strongest correctness check of the compiler port.

## Deliverables (in order)
1. **`listing.rs`** — port of `luac.c`'s `print.c` (`PrintFunction`, `-l` and `-l -l` modes): header line (`main <=chunk:0,0> (N instructions at 0x...)` — the hex address differs per run, so expose a `ListOpts { full: bool, normalize_addresses: bool }` and a CLI-independent function `list(&ProtoData, host, opts) -> String`), per-instruction lines with line numbers, operand formats and `; comments` exactly as `print.c`, constants / locals / upvalues tables. 5.5 specifics (`ivABC`, `GETVARG`, `ERRNNIL`, `NEWTABLE` vB/vC fields) from the vendored `print.c`/`luac.c`. Add a bin target or xtask-callable example `rn-compiler/examples/list.rs <file>` that prints the listing.
2. **Parser + codegen** (`src/v55/{parser,codegen}.rs` or similar; ports of `lparser.c`/`lcode.c`): expression descriptors (`expdesc`, all `VKINT … VVARARG` kinds), register allocation, constant folding (`constfolding`, `luaK_exp2const`), jump list patching, short-circuit / comparison code, `goto`/labels and block close handling, `<const>`/`<close>` attribs, integer/float `for`, closures & upvalue resolution, method calls, `repeat-until` scoping, line info (`savelineinfo`, `ABSLINEINFO` rules), `OP_VARARGPREP`, tail calls, `lcode.c` `luaK_finish`. **5.5-specific features**: read `lparser.c` carefully — `global` declarations (`global x`, `global function`, `global <const> *`), named varargs (`function f(...t)` → `PF_VATAB`, `GETVARG`), the read-only for-loop control variable rules, `ERRNNIL`, any new `luaK_` behaviours. Do not rely on memory of 5.4: follow the vendored 5.5 source line by line.
   - Limits and errors must match: `LUAI_MAXCCALLS` nesting (`chunk has too many syntax levels`), `too many local variables`, `too many upvalues`, `function or expression needs too many registers`, `control structure too long`, `<name> expected near ...`, `attempt to assign to const variable 'x'`, goto/label errors (`no visible label 'x' for goto at line N`), etc.
   - Wire `load()` so text chunks compile (ESC-prefixed still goes to undump). Source `chunk_name` handling and the first-line `#` skip belong to the loader callers (`luaL_loadfilex`), not here; but expose a helper.
3. **Tests & harness pieces** (you create the first version of the V2 tooling):
   - `crates/rn-compiler/tests/bytecode_diff.rs`: for each `.lua` in `vendor/lua-tests-5.5/` (all files, including `libs/*`) and `tests/lua/*.lua`, compare `list(full=true, normalize addresses)` of **our** compile vs `ref/55/build/luac -l -l -p` output (normalize `0x…`). Also compare plain `-l`. Also compile→dump and compare bytes with `luac -o` output (stripped and non-stripped) — byte-identical, which checks lineinfo/locvars/constants ordering. Skips with notice if the ref binary is missing. Report the pass/total number; on failure print a unified-diff-style first-difference hint.
   - `tests/syntax_errors.rs`: ≥ 100 invalid programs (incl. 5.5 `global` misuse, const assignment, goto into scope of local, break outside loop, too many nested levels, unfinished constructs) comparing our error message to `ref/55/build/luac -p -` stderr.
   - Property/regression: deeply nested expressions/blocks must hit the limit error, not overflow the Rust stack (run the compiler on a thread with an explicit stack size in tests, and make the recursion depth limit enforce the reference's `LUAI_MAXCCALLS` = 200).
4. **Add** a generator for extra test programs: `tools/gen_lua_corpus.py` producing ≥ 300 small diverse chunks into `tests/lua/gen/` (arithmetic/constant folding edge cases incl. NaN/-0/inf folding, integer overflow in constants, string escapes, deep upvalue chains, numeric `for` variants, goto/continue patterns, method chains, varargs in every position, multiple assignment evaluation order, operator precedence, comparison chains, `<close>`). Deterministic output (seeded).
