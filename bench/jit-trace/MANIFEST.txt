J5 frozen benchmark programs (docs/JIT_TRACE.md 1.6; task P0). Not to be changed by later tasks (P9 measures them);
new programs may only be informational. Every program takes N = arg[1] (default below), prints one line, and has its
expected stdout in <name>.expected (produced by the reference PUC 5.5 build ref/55/build-seed0/lua and checked equal
with rnlua, RUSTYNAIL_JIT unset and =on). Run all of them with
    PROGDIR=bench/jit-trace scripts/bench-cycles.sh ref=... ours="..."
(the .expected files and the entries marked "bench/programs" are not run by PROGDIR).
